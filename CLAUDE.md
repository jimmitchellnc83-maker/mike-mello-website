# Mike Mello Website — Claude Project Guide

Live at **https://mikemello.com**
Repo: `jimmitchellnc83-maker/mike-mello-website`

---

## Stack

- **Astro** v6.3+ (multi-page static site)
- **Tailwind CSS** v4 (utility-first, configured via `src/styles/global.css`)
- **TypeScript** strict mode
- **Fonts**: Fraunces (Google Fonts, variable — opsz 9..144, wght 300..900, SOFT axis) + Switzer (Fontshare, 400/500/600/700)
- **Deployment**: GitHub Actions auto-deploy on every push to `main` (Node 22) → GitHub Pages
- **Domain**: mikemello.com via Namecheap DNS (DNS-only, no Cloudflare proxy)
- **SSL**: Provisioned and enforced (cert valid Aug 2026)
- **Forms**: FormSubmit wired to murphyjp83@gmail.com (activated)
- **Dev server**: `npm run dev` → http://localhost:4322

## SEO / AEO (All Live)

- Meta tags on every page via `Layout.astro`: description, canonical, Open Graph, Twitter Card
- JSON-LD schemas: Person + WebSite + Service (home), VideoObject x5 (videos), FAQPage (contact)
- Person schema includes `alternateName: ["Mello Mike", "Mike Miller", "Mello Mike Miller"]` and `sameAs` to IMDB, Instagram, X, Facebook
- `/robots.txt` — allows all crawlers including GPTBot, Claude-Web, PerplexityBot
- `/sitemap-index.xml` — auto-generated by @astrojs/sitemap
- `/llms.txt` — entity summary for AI crawlers
- Google Search Console: domain property verified, sitemap submitted
- Bing Webmaster Tools: imported from GSC

## Intentional Decisions — DO NOT UNDO THESE

These were explicit decisions made by the site owner. Do not reverse, re-add, or work around them.

### Sections Deliberately Removed

- **Tour page "Recent Highlights" venue cards** (Segra Stadium, Idiot Box, SECCA, Charlie Goodnight's, Raleigh Improv, Neptunes) — removed because "those are all very old." Do not re-add past venues as a highlights section.
- **Videos page "Featured Special" — What's Seasoning? embed** — HITKOR has embedding disabled, showed a broken image. Do not attempt to embed HITKOR content.
- **Videos page "Podcasts & Appearances" block** (Cary Podcast Ep 37, In TRUE Form, Rhizome Comedy link cards) — removed because "this block needs to come off too, it's not video." Do not add non-video link cards to the videos page.
- **Videos page Incognegro and D.L. Hughley's Speakeasy IMDB cards** — removed from /videos. These credits live on /about only. Do not put them back on /videos.
- **Home page stats row** (20+ Years / 2 Specials / 6 Toured / NBC Finalist) — removed because "those stats are not very impressive." Do not add a stats/numbers row to the home page.
- **Home page "Shared stages with…" + INDY Week pull quote billing block** — removed. Do not re-add shared stages callout or INDY Week quote to the home page.

### Trust Strip (Home Page) — Final Approved List

**Only these five:** D.L. Hughley's Speakeasy · SiriusXM · NBC Stand-Up Diversity · IMDB · WRAL

Do not add INDY Week, Raleigh Magazine, or any other outlet to the trust strip. "No one cares about the INDY."

### Hero Copy — Final Approved State

- **Pill chip text:** "Stand-Up Comedian · Touring Nationally" (not "Raleigh, NC · Stand-Up Comedian" — leaning national, not regional)
- **Pill background:** dark-on-blur (not gold-tinted — readability fix)
- **Tagline:** "Two specials. NBC Stand-Up Diversity finalist. 20+ years on stage." — do not revert to the shared-stages version

### Writing Style — AI Giveaways Scrubbed Sitewide

The site went through an explicit pass to remove AI-flavored copy. Maintain these rules in all future edits:

- **No em dashes (—)** — use pipes, commas, periods, or colons instead
- **No curly apostrophes in TS string literals** — use straight apostrophes only
- **No en-dash numeric ranges** (5–10) — write as plain English
- **No AI-flavored phrases:** avoid "brings X years to any room," "Available for your stage," "the biggest names in stand-up," "from X to Y and everywhere in between"
- Write direct, staccato sentences. No flowery marketing language.

### Images — Known Limitations

- **INDY Week portrait (`indy-week-portrait.jpg`)** — image is auth-locked at the source and was never downloadable. The About page quote section is intentionally text-only. Do not add a placeholder, fallback SVG, or stock image in its place.
- **`incognegro-poster.jpg` and `whats-seasoning-poster.jpg`** — present in `public/images/` but intentionally unused. Do not re-reference them unless the owner explicitly requests it.

### Things That Must Never Appear on the Public Site

- Any reference to the GoFundMe, health issues, or kidney situation
- Any reference to Bunkey's Car Wash or day-job context
- Any personal financial information

### Retired Approaches — Do Not Reintroduce

- The old single-page `index.html` in `mike-mello-site` repo — abandoned, replaced by this Astro multi-page site
- The old slate + amber placeholder palette — replaced by the comedy-stage palette above
- Boska + General Sans font pairing — replaced by Fraunces + Switzer
- Any single-page app or hash-routing approach
